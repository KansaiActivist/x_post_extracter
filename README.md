# X_post_extracter
Python単一が好きなので作成。
# 使い方
シェルで```python daily_post_extracter.py```を実行。
## コマンドオプション解説
例```python daily_tweet_extractor.py --source yahoo --query "" --account GODKAMI17 --keywords "嫌儲,クッキー☆,グッズ,イベント" --max 75```
### souceオプション
ポストを照会するオプションを選択。パラメータはyahooかnitterのどちらか。
### queryオプション
デフォルトで設定されている単語```"学校", "授業", "部活", "宿題", "テスト", "先生", "クラスメイト","通学", "教室", "休み時間", "文化祭", "体育祭", "受験", "塾","家", "自宅", "帰宅", "実家", "晩ごはん", "夕飯", "朝ごはん","洗濯", "掃除", "家事", "寝る前", "起きた", "寝坊""通勤", "満員電車", "電車", "バス", "駅", "会社", "出社","在宅勤務", "残業", "定時", "遅刻", "乗り換え", "始発", "終電","眠い", "疲れた", "お腹すいた", "コンビニ", "ランチ", "お弁当","天気", "雨", "暑い", "寒い",```の中からさらに絞り込むオプション
### accountオプション
ユーザーIDを指定するオプション。@はあってもなくても可。
### debugオプション
デバッグ用のオプション。検索画面のhtmlが出力される。
### keywordオプション
デフォルトで設定されている単語以外を指定出来るオプション。空文字にすると全件取得できる。
### exclude-keywordsオプション
デフォルトで設定されている除外単語```"プレゼント企画", "フォロー&RT", "フォローで応募", "キャンペーン","PR", "広告", "アフィリエイト", "副業", "稼げる", "LINE登録","セール", "クーポン", "今だけ", "無料招待", "URLをクリック","情報商材", "投資", "仮想通貨", "副収入",```以外の除外単語を指定出来るオプション
### keywords-file / exclude-keywords-fileオプション
続けてtxtファイルを指定してキーワード/除外単語を指定出来るオプション。keywords,exclude-keywordsオプションより優先される
### maxオプション
最大取得件数を指定出来る
